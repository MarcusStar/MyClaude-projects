随手记账 · 产品原型

基于 PRD V1.0 (MVP) 实现的可点击原型，目标「3 秒记一笔，月底不糊涂」。所有数据均为 Mock，刷新页面会重新生成。

本页能力

  • 🔐 登录：密码 / 验证码 / 注册三态，含游客体验
  • 📒 明细：日分组流水、左右滑删除、汇总条
  • 📊 统计：月度 KPI + 分类环形图 + 每日柱状图
  • 🎯 预算：进度条 (绿灯/橙灯/红灯)，80%/100% 提醒
  • ⚙ 设置：分类管理、预算设置、数据导出
  • ➕ 记账：半屏弹层，数字键盘 + 分类网格 ≤ 3 步完成

设计参考

  • 无广告 / 无营销推送承诺
  • 预算 ≤ 70% 绿，70–90% 橙，>90% 红 (FR-07)
  • 分类展示支持表格视图 (无障碍替身)

实现要点

单文件原型 — 原生 HTML / CSS / SVG / JS，无任何依赖。所有图表遵守 dataviz 六项校验：

图表选型

  • 支出分类 — 环形图（part-to-whole，≤6 段），尾部合并为「其他」
  • 每日趋势 — 柱状图，一组数据单一 hue（series-1）
  • 预算 — 同色 meter，按阈值切换状态色（good / warning / critical）
  • 细 mark（≤24px 柱，圆角 3）、2px 表面缝隙、1px 网格（无虚线）

可访问性

  • 每张图都有「表格」视图，是无障碍替身
  • 扇区/柱都有 :focus 和 hover 反馈
  • 键盘 focus 可遍历所有可点击元素
  • 系统 prefers-color-scheme 与手动 toggle 都生效
  • 语义标签：<nav>、<section>、role="tablist"

核心 PRD 覆盖

  • 登录 （PRD V1.0 之外，原型补充）：手机号 + 密码 / 验证码 / 注册
  • FR-01 / FR-02 记账弹层
  • FR-03 流水列表（今日/昨日；摘要；日小计）
  • FR-05 流水编辑（点击单条 → 复用弹层）
  • FR-06 统计（环比、KPI、Top 分类）
  • FR-07 预算（进度、阈值提醒）
  • FR-08 分类管理
  • FR-09 CSV 导出

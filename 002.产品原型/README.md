# 002.产品原型 · 随手记账

基于 PRD V1.0 的可交互单页 Web 原型，单文件、无依赖。

## 打开方式

```bash
# 方式 1：直接双击 index.html
# 方式 2：起本地服务（推荐，避免某些浏览器对 file:// 的限制）
python -m http.server 8000
# 然后浏览器访问 http://localhost:8000/index.html
```

## 核心交互

| 操作 | 效果 |
|---|---|
| 打开页面 | 进入登录页（三种方式 + 游客体验），登录后进入 App |
| 登录页切「密码 / 验证码 / 注册」 | 切换表单字段与校验规则 |
| 点「获取验证码」 | 发送演示验证码，进入 60s 倒计时 |
| 点「先逛逛」 | 游客模式直接进入，不写入任何存储 |
| 设置页「退出登录」 | 清除会话，回到登录页 |
| 点击底部 Tab | 切换明细 / 统计 / 预算 / 设置 |
| 点击中央 ➕ | 打开记账弹层 |
| 弹层中：输入金额、选分类、写备注 | 「保存」按钮在金额 > 0 时变绿 |
| 点击单条流水 | 复用记账弹层做编辑 |
| 点击统计/预算 Tab 内的「图表」/「表格」 | 切换对应图表的可视化 |
| 把鼠标 / 焦点放到扇区或柱子 | 显示 tooltip，其他元素淡出 |
| 桌面外侧「深色 / 浅色」 | 切换主题（也跟随系统） |
| 桌面外侧「强制图表 → 表格」 | 全局把两张图都换成表视图（a11y） |
| 桌面外侧「重置 Mock 数据」 | 重新生成随机流水 |

## 登录说明（演示账号）

纯前端 Mock，**没有后端、没有真实鉴权，账号不落库**：

| 方式 | 规则 |
|---|---|
| 密码登录 | 演示账号 `13800138000 / 123456`；其它 11 位手机号视为首次登录自动注册（密码 ≥ 6 位即可） |
| 验证码登录 | 演示验证码固定 `123456`，60s 内有效，过期需重新获取 |
| 注册 | 昵称 + 手机号 + 密码 + 确认密码，密码 ≥ 6 位，两次需一致 |
| 游客体验 | 直接进入，不写 localStorage / sessionStorage，刷新后回到登录页 |

会话持久化：勾「记住我」写 `localStorage`（关闭浏览器仍登录），否则写 `sessionStorage`（关掉标签页即失效），键名 `sjj-auth-v1`。

登录页显示期间，App 主体被设为 `inert`，键盘 Tab 不会跑到被遮挡的界面里。

## 设计参考

- 调色板：取自 dataviz skill 的 [references/palette.md](.palette.md)，已通过 6 项校验。
- 图表：纯 SVG，无第三方库；遵循 dataviz skill 的标记规格（细 mark、2px 表面缝隙、1px hairline 网格、图例永远在场、扇区/柱皆 hover+focus）。
- 主题：CSS 自定义属性 + `data-theme` + `prefers-color-scheme` 三层切换。

## 已知限制（PRD 标注为后续版本）

- 多账本、家庭共享、账单导入、转账等功能不在 V1.0 范围
- AI 语音/拍照记账未做
- 登录只是界面门槛：不校验真实凭证、不发短信、不区分账本（所有账号看到同一份 Mock 数据）
- 数据持久化在内存，刷新或点「重置」会清空 — 用「本地备份」JSON 下载可保留
